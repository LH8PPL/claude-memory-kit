Research agents (e.g., for competitive analysis) follow code-first discipline: full surface enumeration (CLI, tools, config, docs, changelog, tests) *before* conclusions. README-alone analysis is forbidden. Every claim must be cited to file:line. This ensures depth and catches marketing-vs-reality gaps. Agents read the code; synthesis layer reads the reports.

**Why:** Full enumeration caught modules marketing missed (mnemory's sanitize.py, KiroCrew's auto-skill loop). Discipline is now baked into first-pass briefs.

**How to apply:** When preparing research task briefs, mandate code-first enumeration with file-line citation requirements. Expect full surface coverage before allowing synthesis.
