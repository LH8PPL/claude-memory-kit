Finished, tested tasks are released immediately; versions organize batches but don't justify delaying shipping. Real constraint is build time (day-plus pipeline). Versions land frequently (days apart).

**Why:** Maximizes user value delivery and momentum; separates genuine constraints (build pipeline) from artificial ones (version labels)

**How to apply:** Ship finished work immediately; don't hold for other work to build
